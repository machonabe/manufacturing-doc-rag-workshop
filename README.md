# 🏭 製造業向けドキュメント検索 RAG ハンズオン

製造業の技術ドキュメント（試験成績書・Word仕様書・PDFデータシート・ブロック図）を Databricks 上で一元管理し、自然言語で検索 → 関連する図・波形・仕様書を即座に表示する RAG システムをハンズオンで構築します。

## 🎯 ゴール体験

```
質問: 「SNS-200 の過渡応答の試験結果と波形を見せて」

→ Vector Search でセマンティック検索
→ LLM が出典付きで回答生成
→ 関連するブロック図・波形チャートを即座に表示
```

## 📋 前提条件

- Databricks ワークスペース（Unity Catalog 有効）
- サーバレスコンピュート or クラスター
- 所要時間: 約 60〜90 分

## 📁 ノートブック構成

| # | ファイル | 内容 | 所要時間 |
|---|---|---|---|
| 00 | `00_config.py` | 全体共通設定（カタログ・スキーマ・テーブル名） | - |
| 01 | `01_setup_and_sample_data.py` | 環境セットアップ・合成データ生成・VSエンドポイント事前作成 | 10分 |
| 02 | `02_extract_excel.py` | Excel 試験成績書からのメタデータ抽出 | 20分 |
| 03 | `03_extract_docs.py` | Word/PPT/PDF/TIFF/CSV からのテキスト抽出 | 10分 |
| 04 | `04_build_metadata.py` | チャンク化と検索用テーブル作成（CDF + PK） | 10分 |
| 05 | `05_vector_index.py` | Vector Search Delta Sync インデックス作成 | 5〜10分 |
| 06 | `06_rag_query.py` | 自然言語検索 → 図・波形表示（ゴール体験） | 15分 |
| 07 | `07_genie_space.py` | Genie Space で構造化データ探索 | 5分 |
| 99 | `99_cleanup.py` | リソースクリーンアップ | - |

## ⏱️ 効率的な進め方

Vector Search エンドポイントの作成には **10〜20分** かかります。

1. `01` の「VS エンドポイント事前作成」セルまで実行 → **完了を待たずに次へ**
2. `01` の残りと `02`〜`04` を順番に進める（バックグラウンドでプロビジョニング完了）
3. `05` に到達した時点でエンドポイントが準備完了

## 🔧 セットアップ

### 1. Databricks ワークスペースにインポート

```
Repos → Add Repo → https://github.com/machonabe/manufacturing-doc-rag-workshop.git
```

### 2. 設定変更（必要に応じて）

`00_config.py` を開き、以下を環境に合わせて変更:

```python
CATALOG = "workspace"   # Free Edition ではこのまま
SCHEMA = "mfg_doc_search"
```

### 3. 実行

`01_setup_and_sample_data` から順に実行してください。

## 📊 作成されるテーブル

| テーブル | 内容 |
|---|---|
| `documents` | 全ドキュメントのメタデータ（製品ID・種別・パス） |
| `media_assets` | 図・波形とドキュメントの紐付け |
| `excel_cells` | Excel セル単位のメタデータ（取り消し線・結合） |
| `doc_chunks` | Vector Search 用チャンク（CDF有効・PK付き） |
