# 🏭 製造業向けドキュメント検索 RAG ハンズオン

製造業の技術ドキュメント（試験成績書・Word仕様書・PDFデータシート・ブロック図）を Databricks 上で一元管理し、自然言語で検索 → 関連する図・波形・仕様書を即座に表示する RAG システムをハンズオンで構築します。

## 🎯 ゴール体験

```
質問: 「SNS-200 の過渡応答の試験結果と波形を見せて」

→ Vector Search でセマンティック検索
→ LLM が出典付きで回答生成
→ 関連するブロック図・波形チャートを即座に表示
```

## 📋 前提条件

- Databricks ワークスペース（Unity Catalog 有効）
- サーバレスコンピュート or クラスター
- 所要時間: 約 60〜90 分

## 📚 使用している機能の解説

### 1. Unity Catalog
**仕組み:** カタログ > スキーマ > テーブル / Volume の3階層でデータとファイルを統合管理するガバナンスレイヤーです。  
**本ハンズオンでの役割:** 生ファイルは Volume、抽出後のメタデータは Delta テーブルとして保存します。  
**利点:** ファイルと構造化データを同じ権限モデル・リニージで管理できます。

### 2. Delta Lake（CDF + Primary Key）
**仕組み:** Parquet にトランザクションログを加えて ACID とバージョニングを実現します。  
**CDF の役割:** どの行が変更されたかを差分で追跡し、Vector Search の Delta Sync が変更分だけ再同期します。  
**PK の役割:** 各チャンクを一意に識別し、更新時に古いベクトルを正しく置き換えます。  
**利点:** 全件再処理せずに高速・低コストでインデックスを更新できます。

### 3. Databricks Vector Search
**仕組み:** テキストを埋め込みモデルで高次元ベクトルに変換し、ANN（Approximate Nearest Neighbor）検索で意味的に近い文書を探します。  
**構成要素:**
- エンドポイント: インデックスをホストするコンピュート
- Delta Sync インデックス: Delta テーブル変更を自動同期
- マネージドエンベディング: テキスト→ベクトル変換を Databricks が自動実行
**利点:** キーワードが一致しなくても意味が近い技術文書を検索できます。

### 4. Foundation Model APIs
**仕組み:** Databricks 提供の基盤モデルを pay-per-token で API 利用できます。  
**本ハンズオンで使用:**
- `databricks-gte-large-en`: 埋め込み生成
- `databricks-meta-llama-3-3-70b-instruct`: 回答生成
**利点:** GPU クラスター不要、OpenAI 互換 API で呼び出せ、データを Databricks 環境内に保てます。

### 5. RAG（Retrieval-Augmented Generation）
**仕組み:**
1. Vector Search で関連チャンクを検索
2. 検索結果をプロンプトに埋め込む
3. LLM が出典付きで回答生成
**利点:** ハルシネーションを抑えつつ、実際の技術文書に基づく回答ができます。

### 6. Genie Space
**仕組み:** 自然言語を SQL に変換して、登録済みテーブルに対して集計・分析を行います。  
**RAG との違い:**
- RAG: ドキュメントの中身を読む
- Genie: 構造化データを集計する
**利点:** SQL を書けないユーザーでも自然言語で分析できます。

### 7. ドキュメント処理ライブラリ
**使用ライブラリ:**
- `openpyxl`: Excel セル・書式・埋め込み画像
- `python-docx`: Word 段落・表
- `python-pptx`: PowerPoint テキスト
- `pypdf`: PDF テキスト
- `Pillow`: TIFF サムネイル生成
**利点:** フォーマットが不統一な製造業ドキュメントを横断的に扱えます。

### 8. チャンク化の設計思想
**なぜ必要か:** 長文をそのまま埋め込むと検索精度が落ち、モデル入力上限にも引っかかります。  
**本ハンズオンの設計:**
- 800文字単位で分割
- 先頭に製品ID・種別を埋め込み
- Excel はシート単位で分割
**利点:** 「どの製品のどのファイルか」が検索結果からすぐ分かり、図・波形へのナビゲーションもしやすくなります。
